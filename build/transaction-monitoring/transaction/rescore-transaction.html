Rescore Transaction

Reprocess an existing transaction through the fraud scoring rules. Useful when rules have changed or when manual review is complete and a fresh score is needed.

Flat field format

Transaction fields are sent flat at the root of the request body — the same format as Process Transaction. Do not wrap them in a mappedFields object.

API Call​

Send an HTTP POST request to:

POST /api/v1/transactions/{transactionServiceKey}/rescore

Parameters​

ParameterLocationRequiredDescription
transactionServiceKeypath✅Identifier of the transaction service that defines which rules to run
referenceIdbody✅Your internal transaction ID — must match an existing transaction
customerIdbody✅referenceId of the customer
amountbody—Transaction amount. Optional — not all module services require it
(any other key)body—Any additional transaction fields, sent flat at the root

Request​

{
  "referenceId": "a4a4f61d-bd1f-4e8a-b4c2-4c36f9f3a315",
  "customerId": "550",
  "amount": 800,
  "transactionSubType": "0",
  "merchantId": "12345",
  "bnfName": "Name Surname",
  "remitterName": "Name Surname",
  "cardNumber": "1234567891",
  "deviceId": "123456",
  "recognizedDevice": "0"
}
