# Getting Started

## Getting Started
This section describes process of full onboarding - document and person photo collection, verification steps and results return.

## Integration steps 
First, you should create a new session and generate token for it:
- [Create session](./create-session.md)

Second, you should collect and deliver images, there are different approaches for it:

- [Redirect to Web Enrolment](./enrolment.md#redirect-to-web-enrolment)
- [Direct processing](./enrolment.md#direct-processing)

Third, you should get a result of the onboarding to decide if you can trust onboarded person or not:
- [Data](./data.md)
